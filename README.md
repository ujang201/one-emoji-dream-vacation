One emoji, one dream vacation. This program scores a shortlist of candidate
vacation emojis against the judge's five criteria — in the judge's own
priority order — and writes the winner to `/output/entry.txt`.

The winner is Mount Fuji 🗻: a dream destination named outright, a postcard
in a single glyph, one particular trip instead of any holiday, a fresher pick
than the obvious beach, and instantly readable on any screen.

## Run

```sh
node main.ts
```

Writes exactly one emoji (4 bytes, no trailing newline) to
`/output/entry.txt`. Deterministic: every run writes the same bytes.
